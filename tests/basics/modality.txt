# What a thing can do, and a claim held out rather than made.

a wren can fly => learn
can a wren fly? => affirm
can a wren swim? => unsure

a bird can fly
can a heron fly? => affirm
can a trout fly? => unsure

a wren can fly
can a bird fly? => unsure

a cat might be a fish => deny
a cat might swim => unsure

# What a thing is able to do.
devi can swim
can devi swim? => affirm

devi cannot swim
can devi swim? => deny

# What must be so is not what is so.
devi must swim
must devi swim? => affirm
did devi swim? => unsure

# What somebody said is not what the brain holds.
omar said that the ferry is late
is the ferry late? => unsure
did omar say that the ferry is late? => affirm
who said that the ferry is late? => person
