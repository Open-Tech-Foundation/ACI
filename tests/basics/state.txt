# What a thing is like, and that it may stop being so.

a bell is red => learn
is a bell red? => affirm
what colour is the bell? => red

a hut is warm
a hut is cool
is a hut cool? => affirm
is a hut warm? => deny

a bell is red
a bell is blue => learn
is a bell red? => deny
is a bell blue? => affirm

my cat is red
what colour is my cat? => red
what colour is your cat? => I don't know.

a car is red
what size is the car? => I don't know.

# A state changes, and what was so before is still on the record.
the coffee is hot
the coffee got cold
is the coffee hot? => deny
is the coffee cold? => affirm
was the coffee hot? => affirm

# A change told with a clock, and the clock asked back.
the coffee got cold at ten hours
is the coffee cold? => affirm
when did the coffee get cold? => ten hours

# A state reached, with a clock after it, whichever word says reached.
the gate became open at ten hours
is the gate open? => affirm
when did the gate open? => ten hours

# What was so, asked of now.
the gate was open
is the gate open? => unsure

# A thing stands in one state of a scale at a time.
the ball is small
what size is the ball? => small
is the ball big? => deny
